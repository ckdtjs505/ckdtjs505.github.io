\*\*목표\*\*

\* SOOP VOD 플레이어 환경에서 대량(10,000개)의 채팅 패킷을 생성해 자연스럽게 렌더링되도록 주입하는 5단계 레이어 파이프라인의 구조 및 처리 흐름을 체계화합니다.

\*\*기억하기\*\*

\* \*\*VOD vs LIVE 파라미터 차이:\*\* VOD 모드에서 \`rate\`는 초당 전송 수가 아닌 \*\*총 생성 패킷 수\*\*입니다.

\* \*\*단일 벌크 전송:\*\* 1초마다 tick하는 LIVE 모드와 달리, START 시점에 Web Worker에서 10,000개 패킷을 단일 \`\<root>\` XML 덩어리로 일괄 생성해 전송합니다.

\* \*\*오프셋 플레이스홀더 패턴:\*\* 생성 시점에는 \`\_\_VOD\_TIME\_OFFSET\_{s}\_\_\` 형태로 상대 시간을 기록해 두고, 최종 주입 계층(\`page.js\`)에서 실제 \`videoEl.currentTime\`을 기준으로 치환합니다.

\* \*\*크롬 확장 프로그램 격리 환경 통신:\*\* \`popup.js\` → \`chrome.tabs.sendMessage\` → \`content.js\` → \`worker.postMessage\` → \`content.js\` → \`window\.postMessage\` → \`page.js\` 순으로 컨텍스트를 전환합니다.

\*\*내용\*\*

\* \*\*1단계: Popup UI (입력 및 시작 트리거)\*\*

\* \`rate\`(예: 10,000)와 \`durationMs\`(예: 60,000ms)를 입력받아 \`chrome.tabs.sendMessage\`로 \`content.js\`에 START 액션을 전달합니다.

\* \*\*2\~3단계: Worker & vodpackets.js (벌크 XML 생성)\*\*

\* 전체 시간을 기준으로 패킷 인덱스를 균등 분배하여 타임 오프셋(\`s\`)을 계산합니다.

\* \`vodpackets.js\`의 템플릿(\`\_\_VOD\_TIME\_\_\`)을 \`\_\_VOD\_TIME\_OFFSET\_{s}\_\_\`로 변환하고, 10,000개를 하나의 \`\<root>\` 태그로 감싸 단 1회의 \`postMessage\`(\`VOD\_BULK\`)로 내보냅니다.

\* \*\*4단계: Content Script (브릿지 전달)\*\*

\* 확장의 격리된 환경(\`content.js\`)에서 \`window\.postMessage\`를 사용해 메인 페이지 실행 컨텍스트(\`page.js\`)로 XML 데이터를 중계합니다.

\* \*\*5단계: page.js (시간 치환 및 플레이어 큐 주입)\*\*

\* \`videoEl.currentTime + 2초\` 기준으로 정규식을 사용해 오프셋 플레이스홀더를 실제 타임스탬프로 일괄 치환합니다.

\* \`DOMParser\`로 파싱한 10,000개 노드를 순회하며 \`chatItem.createChatData(child)\`를 거쳐 \`chatItem.chats.push()\`로 VOD 플레이어 내부 큐에 직접 삽입합니다.

\| 구분 | LIVE 모드 | VOD 모드 |

\| --- | --- | --- |

\| \*\*패킷 생성 시점\*\* | 1초마다 주기적 tick | START 시점 1회 일괄(Bulk) |

\| \*\*\`rate\`의 의미\*\* | 초당 전송 패킷 수 | 총 주입 패킷 수 |

\| \*\*주입 방식\*\* | \`ctrl.receive()\` (실시간 소비) | \`chatItem.chats.push()\` (큐 사전 적재) |

\| \*\*시간 처리\*\* | 별도 시간 계산 불필요 | 현재 재생 시간 + 상대 오프셋 치환 |

\| \*\*tick 루프 역할\*\* | 패킷 지속 생성 | 성능/메트릭 측정 유지 용도 |

\*\*느낀점\*\*

\* 메인 스레드 부하를 방지하기 위해 10,000개에 달하는 대량 XML 문자열 연산을 Web Worker에 위임하고, 최종 결과물만 단일 메시지로 넘긴 아키텍처가 매우 효율적입니다.

\* VOD의 특성(타임스탬프 기반 재생)에 맞춰 패킷 생성 시점과 실제 주입 시점의 시간 차이를 '오프셋 치환 패턴'으로 분리해 해결한 점이 인상적입니다.

\*\*결론\*\*

\* VOD 환경의 대량 채팅 테스트는 실시간 소켓 주입 방식이 아닌 \*\*사전 일괄 생성 후 플레이어 내부 타임라인 큐 적재 방식\*\*으로 동작합니다. 5단계 레이어를 거쳐 생성 연산(Worker)과 시간 계산/DOM 바인딩(\`page.js\`)의 책임을 깔끔하게 분리한 구조입니다.
